## Código Python

Este fragmento utiliza únicamente la biblioteca estándar de Python. Las tres observaciones son inventadas para ilustrar el formato; no evalúan ningún modelo real.

```python
from statistics import mean

observaciones = [12, 8, 16]  # Datos ficticios e ilustrativos
referencia = [10, 10, 15]

promedio = mean(observaciones)
error_cuadratico = mean(
    (observado - esperado) ** 2
    for observado, esperado in zip(observaciones, referencia, strict=True)
)

print(f"Media ilustrativa: {promedio:.1f}")
print(f"Error cuadrático ilustrativo: {error_cuadratico:.1f}")
```

El [tutorial oficial de Python](https://docs.python.org/3/tutorial/) explica las estructuras utilizadas. El resaltado se genera al compilar el contenido, sin ejecutar el fragmento en el navegador.

## Fórmulas matemáticas

La media de una secuencia se escribe $\bar{x} = \frac{1}{n}\sum_{i=1}^{n}x_i$. Una fórmula en bloque puede expresar el error cuadrático medio:

$$
\operatorname{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2
$$

Aquí $n$ es el número de observaciones y $y_i$, $\hat{y}_i$ son dos valores que se comparan. La fórmula describe una operación matemática; no comunica una medida de rendimiento obtenida en una investigación.
